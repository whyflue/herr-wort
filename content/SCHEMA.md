# Схема банка грамматических материалов

Один файл — одна тема: `content/topics/tNN_<id>.py` со словарём `TOPIC`.
Файлы подхватываются автоматически (`content/__init__.py`), порядок задаёт `nr`.
Эталон — `content/topics/t01_artikel.py`. Проверка: `python check_content.py`.

## Тема (TOPIC)

| Поле | Обязательно | Требования |
|---|---|---|
| `id` | да | латиница, `[a-z_]+`, префикс всех `id` заданий |
| `nr` | да | номер по порядку сюжета, 1–12 |
| `title` | да | русский заголовок с формулами, напр. `Артикли: der/die/das, ein/eine` |
| `short` | да | ≤ 30 символов, для кнопок списка тем, напр. `Артикли` |
| `title_de` | да | немецкое название темы |
| `location` | да | русское название локации, ≤ 40 символов, напр. `Любек, рыночная площадь` |
| `location_de` | да | немецкое название локации |
| `intro` | да | 2–4 предложения: бард приходит в локацию, завязка темы |
| `listen` | да | текст кнопки «Прислушаться»: какие звуки слушает бард |
| `theory` | да | список страниц `{"title": ..., "body": ...}`; `body` ≤ 900 символов |
| `song_line` | да | строфа баллады (1–2 строки, рифмуются), пишется в этой локации |
| `exercises` | да | 6–8 заданий (≥ 5) |

Теория: 2–3 страницы. Русское объяснение с немецкими примерами, уровень A1–A2.
Правила формулируются так, чтобы ими можно было объяснить ошибки в заданиях.

## Задание

Общие поля: `id` (`<id темы>_N`), `kind`, `prompt`, `explain`, опционально `retry`.

- `prompt` — условие по-немецки (для `translate` — русская рамка + фрагмент).
- `explain` — объяснение правила по-русски: показывается и при ошибке
  («фальшивая нота»), и при верном ответе (закрепление).
- `retry` — «похожее» задание того же вида, его выдают при отработке ошибок.
  Схема как у самого задания, без `id` и `retry`.

Виды (`kind`) и механика проверки:

| `kind` | Механика | Обязательные поля |
|---|---|---|
| `mc` | выбор варианта | `options` (2–5, ≤ 40 символов), `answer` (индекс) |
| `gap` | выбор варианта (Lückentext) | то же; в `prompt` пропуск — `___` |
| `join` | выбор варианта (два предложения → одно) | то же |
| `transform` | выбор варианта (плюс → минус, презенс → прошлое) | то же |
| `translate` | выбор варианта (частичный перевод) | то же |
| `order` | сборка предложения тапом по словам | `words` (3–12 слов, верный порядок), `answer` = `" ".join(words)` |
| `error` | поиск ошибки: тап по неверному слову | `sentence`, `wrong` (слово с ошибкой из `sentence`), опц. `fix` `{options, answer}` — выбор верной формы |

## Требования к содержанию

1. **Однозначность.** Среди вариантов ровно один правильный в данном контексте.
   Если вариант может быть верен при другом контексте — уточняй контекст в `prompt`.
2. **Варианты-обманки** должны отражать реальные ошибки русскоязычных студентов
   (падеж, род, порядок слов, окончание), а не случайный мусор.
3. **Никакой синонимии в вариантах**: один и тот же текст (после нормализации)
   дважды не встречается, варианты не совпадают с подписями кнопок-команд
   («Меню», «Дальше» и т. п.).
4. Немецкий — с умляутами и ß, уровень A1–A2, лексика бытовая и «средневековая»
   в рамках сюжета (бард, лютня, рынок, трактир, замок).
5. Объяснения — по-русски, коротко (1–3 предложения), с формулировкой правила.
6. `retry`-варианты не повторяют исходное предложение, а проверяют то же правило
   на новом материале.
