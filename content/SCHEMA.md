# Схема банка грамматических материалов

Один файл — одна тема: `content/topics/tNN_<id>.py` со словарём `TOPIC`.
Файлы подхватываются автоматически (`content/__init__.py`), порядок задаёт `nr`.
Эталон — `content/topics/t01_artikel.py`. Проверка: `python check_content.py`.

## Тема (TOPIC)

| Поле | Обязательно | Требования |
|---|---|---|
| `id` | да | латиница, `[a-z_]+`, префикс всех `id` заданий |
| `nr` | да | номер по порядку сюжета, 1–12 |
| `title` | да | русский заголовок с формулами, напр. `Артикли: der/die/das, ein/eine` |
| `short` | да | ≤ 30 символов, для кнопок списка тем, напр. `Артикли` |
| `short_de` | да | ≤ 30 символов, немецкое короткое название, напр. `Artikel` |
| `title_de` | да | немецкое название темы |
| `location` | да | русское название локации, ≤ 40 символов, напр. `Любек, рыночная площадь` |
| `location_de` | да | немецкое название локации |
| `intro` | да | 2–4 предложения: бард приходит в локацию, завязка темы |
| `listen` | да | текст кнопки «Прислушаться»: какие звуки слушает бард |
| `theory` | да | список страниц `{"title": ..., "body": ..., "body_de": ...}`; `body` и `body_de` ≤ 900 символов каждый |
| `song_line` | да | строфа баллады (1–2 строки, рифмуются), пишется в этой локации |
| `exercises` | да | 25 заданий (валидатор требует ≥ 5) |

Теория: 2–4 страницы. Как и в `exercises.txt`, каждая страница двуязычна:
`body` — объяснение по-русски (с немецкими примерами), `body_de` — то же
правило по-немецки. Бот показывает на экране оба текста (🇷🇺 и 🇩🇪), уровень
A1–A2. Правила формулируются так, чтобы ими можно было объяснить ошибки
в заданиях. Перед заданиями бот отдельно спрашивает, показать правило или
начать без него (`rule_choice`), поэтому теория доступна и до, и во время
прохождения темы.

## Задание

Общие поля: `id` (`<id темы>_N`), `kind`, `prompt`, `explain`, `explain_de`,
опционально `retry`.

- `prompt` — условие задания по-немецки (для свободного ввода — инструкция
  или предложение с пропуском `___`).
- `explain` — объяснение правила по-русски.
- `explain_de` — то же объяснение по-немецки (обязательно, как в
  `exercises.txt`). Бот показывает оба объяснения — и при верном ответе,
  и при ошибке («фальшивая нота»).
- `retry` — «похожее» задание того же вида, его выдают при отработке ошибок.
  Схема как у самого задания, без `id` и `retry`. Если поля нет, при
  отработке повторяется исходное задание.

Виды (`kind`) и механика проверки:

| `kind` | Механика | Обязательные поля |
|---|---|---|
| `mc` | выбор варианта | `options` (2–5, ≤ 40 символов), `answer` (индекс) |
| `gap` | свободный ввод (Lückentext) | `answer` или `answers`; в `prompt` пропуск — `___` |
| `input` | свободный ввод (ответ фразой) | `answer` или `answers` |
| `join` | выбор варианта (два предложения → одно) | как у `mc` |
| `transform` | выбор варианта (плюс → минус, презенс → прошлое) | как у `mc` |
| `translate` | выбор варианта (частичный перевод) | как у `mc` |
| `order` | сборка предложения тапом по словам | `words` (3–12 слов, верный порядок; на экране перемешиваются детерминированно), `answer` = `" ".join(words)` |
| `error` | поиск ошибки: тап по неверному слову | `sentence`, `wrong` (слово или список слов из `sentence`), опц. `solution` — верное предложение, опц. `fix` `{options, answer}` — выбор верной формы вторым шагом |

### Свободный ввод (`gap`, `input`)

- `answer` — единственный верный ответ, `answers` — список допустимых
  вариантов (например, с сокращениями или без них).
- Сравнение не зависит от регистра, пунктуации и `ё/е`; умляуты можно
  писать как `ä/ö/ü/ß`, так и `ae/oe/ue/ss`.
- Ответ не должен совпадать с подписями кнопок-команд после нормализации.

## Требования к содержанию

1. **Однозначность.** Среди вариантов ровно один правильный в данном контексте.
   Если вариант может быть верен при другом контексте — уточняй контекст в `prompt`.
2. **Варианты-обманки** должны отражать реальные ошибки русскоязычных студентов
   (падеж, род, порядок слов, окончание), а не случайный мусор.
3. **Никакой синонимии в вариантах**: один и тот же текст (после нормализации)
   дважды не встречается, варианты не совпадают с подписями кнопок-команд
   («Меню», «Дальше» и т. п.).
4. Немецкий — с умляутами и ß, уровень A1–A2, лексика бытовая и «средневековая»
   в рамках сюжета (бард, лютня, рынок, трактир, замок).
5. Объяснения двуязычны: `explain` — коротко (1–3 предложения) по-русски
   с формулировкой правила, `explain_de` — то же по-немецки. Страницы теории
   тоже двуязычны (`body` + `body_de`).
6. Для заданий `error` в `wrong` перечисляй все слова предложения, которые надо
   считать ошибкой: подойдёт нажатие на любое из них. `solution` показывает
   исправленное предложение.
