# 🎻 Бард — чат-бот ВКонтакте для закрепления немецкой грамматики A1–A2

Образовательный чат-бот: пользователь помогает средневековому барду-новичку
сложить балладу, а сам тренирует грамматику. В каждой локации — одна тема
(12 тем A1–A2), правило, задания и разбор ошибок. За пройденную тему бард
дописывает строчку песни.

Два режима, как в описании проекта:

- **Сюжет** — путь барда по городам: локация → выбор «показать правило»
  или «начать без правила» (можно и «прислушаться» до этого) → задания →
  разбор ошибок → отработка сложных мест → строфа песни → следующая
  локация → финал → возвращение в знакомые места / начать заново.
- **Тренировка по темам** — без сюжета: выбор темы → выбор правила →
  задания → результат, с теми же механиками (объяснение правил, фальшивые
  ноты, отработка проблемных заданий).

## Маршрут барда: 12 тем

| № | Тема | Локация |
|---|---|---|
| 1 | Артикли: der/die/das, ein/eine | Любек, рыночная площадь |
| 2 | Множественное число существительных | Гамбург, порт |
| 3 | Личные местоимения и глагол в Präsens | Бремен, трактир у ратуши |
| 4 | Отрицание: nicht и kein | Кёльн, у собора |
| 5 | Модальные глаголы: können, müssen, wollen | Нюрнберг, замок мастера |
| 6 | Отделяемые и неотделяемые приставки | Веймар, мельница у реки |
| 7 | Аккузатив и датив | Вена, императорский двор |
| 8 | Perfekt с haben и sein | Ротенбург-на-Таубере, городская стена |
| 9 | Претеритум: sein, haben, модальные глаголы | Вартбург, замок легенд |
| 10 | Придаточные с weil, dass, wenn | Гейдельберг, библиотека |
| 11 | Склонение прилагательных | Страсбург, площадь у собора |
| 12 | Пассив (Präsens, Präteritum) | Аахен, собор Карла Великого |

В каждой теме 25 заданий — всего 300 заданий, которые бот проверяет
автоматически. Виды заданий: выбор варианта, свободный ввод пропуска или
ответа фразой, сборка предложения из слов и поиск ошибки в предложении.

## Установка

```powershell
cd E:\vkbot
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Зависимости: `vk_api` (longpoll и методы VK) и `python-dotenv` (чтение `.env`).
Бот работает только от имени сообщества: в `.env` впишите токен сообщества
`VK_GROUP_TOKEN` (как его получить — ниже).

## Работа от имени сообщества

Бот отвечает от имени сообщества (паблика): студент видит его название
и аватар, личный аккаунт нигде не светится, а ограничения на рассылку мягче.
Нужно только сообщество — новый аккаунт создавать не требуется.

1. Создайте сообщество: `vk.com/groups` → «Создать сообщество» (подойдёт
   публичная страница «Изучение немецкого»).
2. «Управление» → «Сообщения»: включите переключатели **«Сообщения
   сообщества»** и **«Возможности ботов»**. Там же убедитесь, что писать
   сообщения можно всем.
3. «Управление» → «Работа с API» (в некоторых версиях интерфейса —
   «Настройки» → «Работа с API»):
   * вкладка **«Long Poll API»** — включите Long Poll API, версия 5.199;
   * вкладка **«Типы событий»** — отметьте **«Входящие сообщения»**;
   * вкладка **«Ключи доступа»** → **«Создать ключ»** — отметьте галочки
     **«Управление сообществом»** и **«Сообщения сообщества»**, подтвердите
     кодом из SMS.

   Галочка «Управление сообществом» обязательна: без неё VK не отдаёт
   Long Poll (бот сразу напишет об этом в логе кодом 15).

4. Скопируйте ключ (он начинается на `vk1.a.`) и впишите в `.env`:

   ```
   VK_GROUP_TOKEN=vk1.a.ваш_ключ
   ```

Ключ сообщества не позволяет писать первым: бот отвечает тем, кто написал
ему сам. Для учебного бота это как раз то, что нужно.

## Запуск

```powershell
python check_content.py     # проверить банк материалов (схема, лимиты кнопок)
python main.py              # запустить бота: longpoll, окно должно быть открыто
```

Первая строка в логе подскажет, какое сообщество ведёт бота:
«Бот запущен от имени сообщества «...»».

Бот отвечает, пока запущен `main.py`. Для апробации удобно держать процесс
на сервере (VPS) или хотя бы на включённом компьютере.

Студент открывает страницу сообщества (`vk.com/clubNNNNNN`), нажимает
«Написать сообщение» и пишет `начать`.

## Прогон без VK

Движок не зависит от VK, поэтому весь сценарий можно проходить в консоли:

```powershell
python simulate.py                     # интерактивный диалог, как в VK
python simulate.py --auto              # автопрогон сюжета с верными ответами
python simulate.py --auto --wrong      # прогон с ошибками: фидбэк и отработка
python simulate.py --auto --mode all   # сюжет + места + тренировка по темам
python simulate.py --db sim.db         # сохранить прогресс в файл
```

Автопрогон полезен как дымовой тест после правок контента или движка.

## Как играть (кратко для студента)

- **Задания решаются кнопками или текстом.** В режиме выбора — нажми
  вариант; если нужно написать слово или фразу — отправь ответ сообщением
  (регистр, пунктуация и умляуты не важны: `ä` можно писать как `ae`);
  в задании «собери предложение» — нажимай слова по порядку, «Убрать слово»
  удаляет последнее, «Проверить» завершает; в задании «найди ошибку» —
  нажми на неверное слово.
- **Ошибка = фальшивая нота.** Бот показывает верный ответ и объясняет
  правило по-русски, а для ошибок — ещё и по-немецки.
- **Отработка.** Перед переходом дальше бот предлагает повторить задания,
  в которых были ошибки. Отработанная ошибка закрывается в статистике.
- **Прогресс** хранится в базе: строфы баллады, результаты по темам и список
  незакрытых ошибок (экран «Статистика»).
- **Заново.** Сюжет можно начать заново в любой момент; история ошибок
  при этом сохраняется.

## Как добавить или поправить тему

1. Скопируйте `content/topics/t01_artikel.py` в `content/topics/tNN_<id>.py`
   и заполните словарь `TOPIC`. Требования — в `content/SCHEMA.md`:
   `nr`, `title`, `short`, `location`, `intro`, `listen`, `theory` (2–3
   страницы), `song_line` (двустишие баллады), 25 заданий.
2. Виды заданий: `mc` (выбор варианта), `gap` и `input` (свободный ввод),
   `order` (сборка предложения из слов), `error` (поиск ошибки).
   Все проверяются автоматически, без ИИ: варианты отдаются кнопками, поэтому
   подпись варианта — не длиннее 40 символов.
3. Запустите `python check_content.py` — валидатор проверит схему, длину
   подписей, уникальность вариантов, отсутствие конфликтов с кнопками-командами
   и то, что все клавиатуры влезают в лимиты VK.
4. Прогоните `python simulate.py --auto --mode all` — сценарий должен
   проходить без ошибок.

Новые темы подхватываются автоматически: файлы `content/topics/t*.py`
собираются в список по возрастанию `nr`.

## Технические детали

- Транспорт — **Bots Long Poll API** сообщества
  (`vk_api.bot_longpoll.VkBotLongPoll`, адресат — `peer_id` диалога).
  Движок от транспорта не зависит. У longpoll
  **не приходят callback-события**, поэтому кнопки текстовые: нажатие
  кнопки — обычное входящее сообщение, движок сопоставляет его с вариантом
  ответа или командой.
- Ответ можно и напечатать руками — сравнение идёт по нормализованному тексту
  (регистр, пунктуация, эмодзи не важны; `ä/ö/ü/ß` можно набирать как
  `ae/oe/ue/ss`).
- Состояние диалога хранится в таблице `users` (JSON), прогресс — в
  `progress`, ошибки — в `mistakes`, результаты попыток — в `attempts`.
- `messages.edit` используется только для обновления экрана при сборке
  предложения из слов; при ошибке правки бот отправляет новое сообщение.

## Если что-то не работает

- **«В .env не задан VK_GROUP_TOKEN»** — создайте `.env` из `.env.example`
  (`Copy-Item .env.example .env`) и впишите токен сообщества.
- **Код 15 «Access denied … current scopes»** — у ключа
  сообщества нет галочки «Управление сообществом»: перевыпустите ключ
  в «Управление» → «Работа с API» → «Ключи доступа», отметив обе галочки —
  «Управление сообществом» и «Сообщения сообщества».
- **Бот молчит, хотя сообщение отправлено** — процесс `main.py` должен быть
  запущен. Напишите сообществу первым (ключ сообщества не может писать
  первым) и убедитесь, что в «Управление» → «Сообщения» включены «Сообщения
  сообщества» и «Возможности ботов», а в «Работа с API» → «Типы событий»
  отмечены «Входящие сообщения».
- **Кнопки не отображаются** — весь сценарий доступен и текстом: пишите
  «меню», «сюжет», «тренировка», «дальше», «проверить», а ответы либо
  вариантами («den»), либо словами по одному сообщению.
- **Нужно посмотреть, что происходит** — запустите `python simulate.py`:
  это тот же движок, что и в VK, но в консоли.

## Результаты и апробация

На экране «📊 Статистика» игрок видит свою точность, прогресс по локациям и
незакрытые ошибки. Для разбора после апробации есть отдельный инструмент:

```powershell
python stats.py                      # сводка по всем, кто играл
python stats.py --user 123456        # подробно по одному игроку
python stats.py --csv report.csv     # таблица для отчёта (Excel)
```

Анкета для целевой группы, порядок проведения сессий и способ свести
результаты — в `docs/anketa.md`.

  таблица тем, статистика прогона из `simulate.py`.
